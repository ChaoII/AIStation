# AI 办公室 · 人物模型规范（给 Blender 建模用）

> 目标：办公室里的 agent 人物从「程序化小人」升级成**带骨骼的 glTF 角色**，
> 高配机器用模型，低配机器自动回落到现有小人；换发型 / 换衣服 / 换鞋在运行时完成，
> 不需要重新导出模型。
>
> 建模软件：本机已装 **Blender 4.5** 与 **5.1.2**（`C:\software\Blender Foundation\`）。
> 两个版本导出的 glTF 2.0 是一致的，用哪个都行；**5.1.2 足够，不需要再装新版**。

---

## 一、交付物

一个文件：`frontend/src/assets/office/agent.glb`

要求（硬性）：

| 项 | 要求 |
|---|---|
| 格式 | **glTF 2.0 Binary（.glb）**，贴图内嵌 |
| 单位 | 米（Scene Properties → Units → Metric，Scale 1.0） |
| 身高 | 站在地面时**头顶 1.70 m**，脚底在 y = 0 |
| 朝向 | **面朝 +Z**（Blender 里是 -Y 为前，导出时用默认 glTF 转换即可；导出后我会再校验一次） |
| 轴 | Y 向上（glTF 默认，导出时不要勾 "Y Up" 的反向选项） |
| 三角面 | **3 000 – 8 000**（办公室 50 人，面数再高会掉帧） |
| 贴图 | 单张 512×512 或 1024×1024（不要 PBR 多图，颜色尽量走顶点色或单张图） |
| 相机/灯光 | **不要导出**（Export → Include → 只勾 Selected Objects 或删掉相机灯光） |
| 原点 | 角色根节点在脚底中心（0, 0, 0） |

## 二、骨骼（Armature）

命名固定，我会按这套名字找骨（大小写敏感）：

```
Root
└─ Hips
   ├─ Spine
   │  └─ Chest
   │     ├─ Neck
   │     │  └─ Head
   │     ├─ UpperArm.L → LowerArm.L → Hand.L
   │     └─ UpperArm.R → LowerArm.R → Hand.R
   ├─ UpperLeg.L → LowerLeg.L → Foot.L
   └─ UpperLeg.R → LowerLeg.R → Foot.R
```

- 只做**FK**即可，不需要 IK / 控制器骨架（导出前把约束烘焙掉或直接不导出控制骨）。
- 手指不需要骨骼（手可以是一整块）。

---

## 三、动作（Animation）

四条，**名字必须完全一致**，各占独立 Action：

| Action 名 | 时长 | 循环 | 说明 |
|---|---|---|---|
| `idle` | 48 帧 @24fps（2s） | 是 | 坐着呼吸 + 轻微抬头；站着的版本也行，我会按座位切换 |
| `walk` | 32 帧 @24fps | 是 | 走到位循环；**原地**走（不位移，位移由代码控制） |
| `dance` | 48 帧 @24fps | 是 | 蹦迪：上下颠 + 摆胯，幅度大一点 |
| `sing` | 48 帧 @24fps | 是 | 主唱：一手拿话筒到嘴边、头微仰 |

- 动作**不需要位移**（root motion 关掉），也不要缩放骨。
- 帧率 24 即可，导出时 glTF 会存成秒。

---

## 四、换装（部件拆分）

同一角色的**头发 / 上衣 / 裤子 / 鞋子**各做成独立 mesh，命名：

```
hair_0, hair_1, hair_2 …        （发型；同一时刻只显示一个）
shirt_0, shirt_1, shirt_2 …     （上衣）
pants_0, pants_1 …              （裤子）
shoes_0, shoes_1 …              （鞋）
body                             （身体本体，必留）
```

- 每个部件都**绑同一套骨架**（同一个 Armature modifier），这样换装不会散架。
- 我运行时按名字显示/隐藏，**不重导出模型**。
- 颜色：材质名按 `mat_shirt` / `mat_pants` 等固定命名，我在代码里改 `material.color`；
  如果某件衣服有自己的贴图，直接用它自己的材质也行（我只改没贴图的那几件）。

## 五、我会做的适配（你不用管）

1. **加载与降级**：启动时按硬件（核显 / 掉帧 / 移动端）判断；
   低配继续用现在的程序化小人，高配换成 `agent.glb`；
   `⋯` 菜单里会加「画质：自动 / 高 / 低」手动开关。
2. **动作状态机**：坐下→`idle`，走路→`walk`，舞池→`dance`/`sing`，被打断立刻切回 `walk`。
3. **换装**：现有「改形象」面板的发型/上衣/裤子/鞋直接映射到上面的 mesh 名，颜色写进材质。
4. **工牌 / 气泡**：仍然用现有的 HTML 名牌，不塞进模型里。
5. **校验脚本**：模型放进来后，我会用 Blender headless 跑一遍检查
   （骨骼名、动作名、朝向、身高、面数），有问题会列出来给你，不会默默用坏的模型。
