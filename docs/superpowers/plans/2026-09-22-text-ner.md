# 文本 NER 标注 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给标注系统新增「文本」媒体类型与 `text_ner` 标注任务，支持用户上传文本文件并在其上做**实体 + 关系**标注（字符级连续 span `EntitySpan` + 同句内 `Relation`），导出为**字符级 BIO/BIESO** 序列标注 + 关系 JSON。

**Architecture:** 后端新增 `AnnotationDocumentModel` + `AnnotationType.TEXT_NER` 枚举，文本文件存 RustFS 并做编码探测/UTF-8 规范化、算字符数/行数/去重哈希；标注记录增加 `document_id`。前端工作台对 `text_ner` 任务用 **CodeMirror 6** 只读文本 + Mark-decoration 高亮实体，鼠标拖选生成 `EntitySpan`，右侧面板管理实体/关系（列表 + 联动高亮），标注按 `document_id` 读写；导出为字符级 BIO/BIESO + `relations.jsonl`。

**Tech Stack:** FastAPI / SQLAlchemy 2.0 / Pydantic v2 / PostgreSQL / Alembic / RustFS(S3) / Vue 3 + Vite + Element Plus + TS / CodeMirror 6（已内置）/ Vitest / Playwright e2e。

## Global Constraints

- **编辑器**：文本 span 标注必须用 **CodeMirror 6**（现有依赖），禁止手写编辑器/富文本/自拼装；正文 `EditorState.readOnly` 只读，仅允许选区；用 `Decoration.mark` 高亮实体；用 `state.selection` 取 `[from,to)`（UTF-16 offset）生成实体。
- **字符偏移统一 UTF-16 code unit**（与 JS/CodeMirror 一致）；后端在需要时做 code point ↔ UTF-16 换算；`EntitySpan.text` 冗余存原文。
- **关系**：同句内两实体；`from/to` 为实体 id，`relation_type` 取 `classes.relations`。不在文本框上画 SVG 线，用右侧列表 + 联动高亮。
- **类型配置**：`text_ner` 任务 `classes` 为 dict `{entities:[...], relations:[...]}`。
- **媒体/形状**：`TaskMedia` 加 `"text"`；新增 `textNerPlugin`（自建渲染/工具，不走 SVG 几何坐标系）。
- 文本上传白名单扩展名（`.txt/.text/.md/.csv/.tsv/.json/.log` 等）；大小上限（2MB/20 万字符）；编码 utf-8→gbk→latin1 兜底，写回时统一 UTF-8；文件按 `content_hash` 去重。
- 遵循 `AGENTS.md`：局部刷新优先（实体/关系变更只更新对应 decoration/列表项，禁止整页重渲染）；`el-*` 组件与 `--el-*` 变量、禁止写死 `font-size`；删除/覆盖类操作二次确认；组件单根；中文注释与提交信息（`feat|fix(annotation): 中文`）。
- 后端提交信息格式 `feat|fix(annotation): 中文`；前端 `feat|fix(annotation): 中文`。
