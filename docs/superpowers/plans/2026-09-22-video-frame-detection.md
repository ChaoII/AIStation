# 帧级视频检测标注 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给标注系统新增「视频」媒体类型与 `video_detection` 标注任务，支持用户上传视频并**逐帧**标注 2D 检测框（`AxisAlignedBox`），按帧复用现有检测导出链路。

**Architecture:** 惰性视频帧视图——后端新增 `AnnotationVideoModel` + `AnnotationType.VIDEO_DETECTION` 枚举，视频存 RustFS 并用 ffprobe 探测 `duration/width/height/fps/frame_count`；前端工作台对 `video_detection` 任务用 `<video>` 元素 seek 到当前帧并叠加检测标注（复用 `detectionPlugin`），标注按 `video_id + frame_index` 读写，导出时按帧抽图复用检测链。

**Tech Stack:** FastAPI / SQLAlchemy 2.0 / Pydantic v2 / PostgreSQL / Alembic / ffmpeg+ffprobe / RustFS(S3) / Vue 3 + Vite + Element Plus + TS / Vitest / Playwright e2e。

## Global Constraints

- 复用现有检测插件与 `AxisAlignedBox`，**无新增形状类型、无新增导出逻辑**。
- 标注按 `video_id + frame_index` 组织/保存/读取；`frame_index = round(time × fps)`。
- 惰性帧视图：不预抽帧，前端 `<video>` seek。
- 视频存 RustFS（`s3_client`），元数据 ffprobe 探测。
- 遵循 `AGENTS.md`：局部刷新优先（帧状态落到行数据/局部组件，禁止整表刷新）；`el-*` 组件与 `--el-*` 变量、禁止写死 `font-size`；删除/覆盖类操作二次确认；组件单根；中文注释与提交信息（`feat(annotation): 中文描述`）。
- 后端提交信息格式 `feat|fix(annotation): 中文`；前端 `feat|fix(annotation): 中文`。

```python
import json, subprocess

def _run_ffprobe(path: str) -> dict:
    cmd = ["ffprobe", "-hide_banner", "-loglevel", "error",
           "-print_format", "json",
           "-show_streams", "-show_format", path]
    out = subprocess.run(cmd, capture_output=True, text=True)
    return json.loads(out.stdout)

def _probe_video(path: str) -> dict:
    data = _run_ffprobe(path)
    v = next((s for s in data.get("streams", []) if s.get("codec_type") == "video"), {})
    w, h = v.get("width", 0), v.get("height", 0)
    rate = v.get("r_frame_rate", "0/1")
    num, _, den = rate.partition("/")
    fps = float(num) / float(den) if den and float(den) else 0.0
    duration = float(data.get("format", {}).get("duration", 0) or 0)
    return {"width": w, "height": h, "fps": fps, "duration": duration,
            "frame_count": round(duration * fps)}
```
