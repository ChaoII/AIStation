# 前端国际化（阶段一 + module_system 试点）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完善前端 i18n 基础设施，并把 `module_system` 模块全部界面文案接入中英文切换，作为全平台范本。

**Architecture:** 沿用现有 `vue-i18n`（`legacy:false`），把语言包按模块拆分聚合；用 `$t('namespace.key')` 替换 `.vue`/`.ts` 中的硬编码中文；Element Plus 内置文案已由 `appStore.locale` 随语言切换；新增检测脚本作为「未翻译串」验收基线。

**Tech Stack:** Vue 3 + vue-i18n v11 + Element Plus（`el-config-provider` locale 已接）+ Vite + TypeScript。

**Spec:** `docs/superpowers/specs/2026-10-23-frontend-i18n-design.md`

## Global Constraints

- 所有对用户的回复用中文；代码注释用中文。
- key 命名：`命名空间.元素.语义`，如 `system.user.search.name`、`system.role.deleteConfirm`。
- 中英文同一 key 分别落在 `zh-cn`/`en` 对应模块包；`ts` 内用 `t()`（需 import），模板用 `$t()`。
- 含变量/模板的文案用 vue-i18n 插值语法 `{n}`，翻译保留占位符。
- 不改后端错误/枚举文案；菜单标题走 `route.*` key。
- 每模块完成后必跑 `pnpm run type-check`。

## Review Focus

- 语言包 key 缺失/拼写不一致导致 `$t` 渲染出 key 名（切英文后出现 `system.user.xxx` 字样）→ 用检测脚本 + type-check 兜底。
- 模板字符串带插值（如「将删除 {n} 项」）未用 `{n}` 语法 → 翻译后占位符丢失/散乱。
- `translateRouteTitle` 未命中导致菜单标题切英文仍中文 → 为所有 `module_system` 菜单路径补 `route.*`。
- 切回中文后 key 返回 undefined → 中英包 key 必须成对补齐。
- Element Plus 内置组件（分页/空态/筛选）切英文仍中文 → 确认 `appStore.locale` 返回对象而非字符串。

### Task 3: 新增「未翻译中文串」检测脚本

**Files:**
- Create: `frontend/scripts/check-i18n-missing.mjs`

**Interfaces:**
- Produces: `node scripts/check-i18n-missing.mjs <dirPath>` 扫描 `<dirPath>` 下 `.vue`/`.ts`，用正则抓取中文字面量（中文在 `/[\u4e00-\u9fff]/`），排除已包在 `t(`/`$t(`/`$t(` 调用内的，输出「文件:行: 中文串」清单；`--dir=src/views/module_system` 时仅扫该系统目录。退出码 0 表示无遗漏（或 `--lenient` 允许有）。

**步骤：**

- [ ] **Step 1: 实现脚本**

抓取逻辑：对每个文件文本，遍历匹配含中文的字符串/模板文本；跳过已用 `t(` 或 `$t(` 包裹的上下文（启发式：所在行含 `$t(`/`t(` 且中文在参数内时视为已处理）；输出剩余中文串。

- [ ] **Step 2: 自测**

Run: `node scripts/check-i18n-missing.mjs src/views/module_system/auth`
Expected: 输出该目录未翻译中文串（登录页在 Task 4 前应有多条），证明脚本能抓。

- [ ] **Step 3: Commit**

```bash
git add scripts/check-i18n-missing.mjs
git commit -m "feat(i18n): 新增未翻译中文串检测脚本"
```
