# 计划：问数「困难题/自定义报表」收尾四项

> 承接 `2026-10-11-ai-query-report-and-clarify-design.md`。
> 已完成：人类反馈链路、澄清反问、报表模板后端、前端三链路。
> 本计划做完剩下四项，**每项都要有自动化测试**，最后**用浏览器自动化核对界面**。

## 任务清单

| # | 任务 | 交付 | 验收 |
|---|------|------|------|
| 1 | **结果自校验** | `query/selfcheck.py`：占比合计≈100%、排名连续、行数量级、累计单调 | 纯函数单测；接入慢路径，命中则带错因重试一次 |
| 2 | **两段式分解生成** | `query/plan.py`：先出执行计划（选表/联表/分组/排名/过滤/输出列），再据计划生成 SQL | 纯函数单测（计划解析/降级）；`decomposed_planning=true` 时启用 |
| 3 | **报表管理页** | `frontend/src/views/module_ai/query/reports.vue`：列表/运行/确认/删除 + 菜单 | type-check 0 错误；接口联通 |
| 4 | **浏览器自动化核对** | 截图 + 我自己的多模态读图 | 与既有页面风格一致；三条链路可见可用 |

## 实施顺序

1 → 2（后端，TDD）→ 3（前端）→ 4（视觉核对）。

## 约束（来自 AGENTS.md）

- 前端只用 Element Plus + `--el-*` 变量，**不自造主题外壳**；
- 布局用 `el-row/el-col`，不用自定义 Grid；
- 删除类操作**必须二次确认**（`ElMessageBox.confirm`，写明数量与不可逆）；
- 页面**单根元素**；弹窗放根元素内；
- **局部刷新**，不整表轮询；
- 完成后**用无头浏览器截图 + 我自己读图**核对（不依赖 vision 技能）。

## 风险

- 两段式分解会**增加一次 LLM 调用**（延迟↑）→ 必须**只在 `decomposed_planning=true` 且题目判定为"多步"时启用**，并在计划失败时**降级**为单段生成；
- 自校验若**误报**会把正确结果判成可疑 → 只做**提示 + 一次重试**，不阻断返回。
