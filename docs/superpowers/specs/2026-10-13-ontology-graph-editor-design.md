# 本体图谱化编辑 —— 设计

> 背景：本体页当前是「左侧 20 个 tab + 右侧清单」的导航式布局，用户反馈「稀稀拉拉、不够紧凑、搜索结果/概览等 page 定位不清」。
> 用户明确想要的：**把本体核心编排（对象类型 / 关系类型 / 各自的属性 / 动作 / 函数）融合进一张可编辑图谱**，替代单纯罗列的 tab 清单。
> 技术红线：**图谱用 cytoscape（前端空间渲染），严禁自绘 SVG**（性能差）。项目已有 `GraphCanvas.vue`（cytoscape 封装）可直接复用。

## 1. 目标与转变

| 现在（稀稀拉拉） | 目标（图谱化编辑） |
|---|---|
| 右侧 20 个 tab 平铺 | 右侧一张大图谱：节点=对象类型、边=关系类型 |
| 看结构靠点 tab | 结构一眼可见，点节点弹详情 |
| 编辑散在各清单页 | 图谱上直接双向编辑（拖拽建边 / 右键新建 / 删除） |
| 辅助功能跟图谱平级抢 tab | 辅助功能收进「维护」下拉 / 抽屉，不占图谱主体 |

## 2. 信息架构

```
┌─ 左栏：本体列表 ──────┐  ┌─ 右栏：图谱工作区 ─────────────────────────────┐
│ 本体 + 新建本体         │  │ 工具条:[当前本体] [搜索对象] [布局▾] [缩放/适配] │
│ ▸ 数据表本体 (操作…)    │  │        [图例] [只显示有关联▾] [概览][维护▾][保存/丢弃]│
│ ▸ 本体B               │  ├──────────────────────────────────────────────┤
└───────────────────────┘  │           GraphCanvas (cytoscape 全屏)          │
                            │    节点 = 对象类型  边 = 关系类型                │
                            └──────────────────────────────────────────────┘
                          （点节点 → 右侧弹出「对象详情」抽屉）
```

## 3. 图谱工作区（复用 GraphCanvas）

- **节点** = 当前本体下的对象类型（`scopedObjects`）；**边** = 关系类型（`scopedLinks`）
- 布局：力导向 / 同心 / 树形 / 网格 / 环形（GraphCanvas `layoutName` 已内置）
- 节点尺寸/颜色/形状按对象类型区分，悬停高亮 + 邻接变暗 + tooltip（GraphCanvas 内置）
- 点节点 → 右侧**对象详情抽屉**（复用 `OntObjectTypeView` 全部能力：元数据/属性/动作/函数/安全/数据源/关系图/使用量）
- **筛选栏**（工具条上的开关）：
  - 「只显示有关联的对象」：过滤掉 `link_count === 0` 的孤立对象，保持图谱清爽
  - 「搜索对象」：`graphRef.search(name)` 定位高亮（GraphCanvas 已暴露 `search`）
  - 「按分组过滤」：按对象 `domain_code` 分组开关（本体内再分组）

## 4. 双向编辑（走暂存，右上角保存/丢弃）

| 操作 | 交互 | 复用入口 |
|---|---|---|
| 新建对象类型 | 右键空白 → 新建 | `openObjectEdit(null)` |
| 编辑对象元数据 | 右键节点 → 编辑 | `openObjectEdit(obj)` |
| 删除对象 | 右键节点 → 删除（二次确认） | `removeObj(obj)` |
| **创建关系** | **拖拽节点→节点**（GraphCanvas `linkMode` → `link-draw` 事件） | `openLinkEdit()` 预填源/目标 |
| 编辑/删除关系 | 点边 → 面板编辑 | `openLinkEdit(link)` |
| 新建属性/动作/函数 | 对象详情抽屉内 | `openActionEdit()` / `openFuncEdit()` |
| 物化为表 | 右键节点 → 物化 | `materialize(obj)` |

所有改动走现有 `stage()` 暂存机制，右上角「保存」才落库，符合项目既有「工作副本 + 审核」模式。

## 5. 辅助功能收纳（右侧抽屉）

右侧不再有 tab。所有辅助功能通过工具条打开 **`el-drawer`（右侧抽屉）**，不影响图谱主体空间。

### 5.1 「概览」抽屉
工具条「概览」按钮打开。内容 = 原 `page === 'overview'` 全部：演示数据（载入/清除/报告）、统计卡片、从数据源导入表结构、应用行业本体模板。

### 5.2 「维护」下拉 → 各辅助功能抽屉
工具条「维护」下拉，每项打开对应抽屉，收纳以下原 tab 页：

| 抽屉 | 内容来源 |
|---|---|
| 对象探索 | 原 `page==='explore'`（`OntInstanceExplorer`） |
| 索引 | `OntIndexView` |
| 提案 | `OntProposalView` |
| 场景 | `OntScenarioView` |
| 决策 | `OntDecisionView` |
| 健康检查 | 原 `page==='health'`（内联） |
| 清理 | 原 `page==='cleanup'`（内联） |
| 历史 | 原 `page==='history'`（内联） |
| 使用量 | 原 `page==='usage'`（内联） |
| 导入导出 | 原 `page==='transfer'`（内联） |
| 高级类型 | `OntAdvancedTypes` |
| 接口 / 共享属性 | 原 `page==='interfaces'/'shared'`（`OntAdvancedTypes`） |

> 说明：原 tab 页多数内联在 index.vue 模板。设计上**抽取为独立抽屉内容组件**（或以 `v-show` 包裹在 drawer 内复用现有模板），避免 index.vue 继续膨胀。

## 6. 分阶段交付（用户选定 B：分步、每步可验证）

### 阶段 1：图谱骨架
- 右栏改为图谱工作区（GraphCanvas）渲染当前本体的对象+关系
- 内嵌筛选（只显示有关联 / 搜索 / 布局切换）
- 点节点 → 右侧对象详情抽屉（复用 OntObjectTypeView）
- 保留左栏本体列表联动（切本体 → 图谱重绘）
- **此阶段图纸谱只读浏览，无编辑**

### 阶段 2：双向编辑
- 拖拽建边 → 关系编辑
- 右键新建/编辑/删除对象
- 走暂存（保存/丢弃）

### 阶段 3：辅助功能抽屉
- 「概览」抽屉 + 「维护」下拉内各辅助抽屉
- 抽取内联模板为抽屉组件
- 删除旧 tab 导航

## 7. 测试

- 前端 `pnpm run type-check`（AI 模块 0 错误）
- 无头浏览器截图验证各阶段图谱渲染、对象详情抽屉、编辑交互、辅助抽屉
- 真机验证：切本体重绘、点节点弹详情、拖拽建边走暂存、右键删除二次确认

## 8. 不做（YAGNI）

- 不新建图数据库 / 后端图接口（复用现有 objects/links/actions/functions API）
- 不自绘 SVG 图谱（强制 cytoscape）
- 不做图谱上「连线拖拽时动态建临时对象」（仅现有对象间建关系）
- 一次性改完——按阶段逐步交付
