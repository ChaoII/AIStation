## 4. 同一套 105 题（ds:6）

- **104 / 105 = 99.05%**
- 唯一失败：「入厂煤批次一共有多少条？」平台指标按软删过滤返回 **522**，
  评测金标沿用全量 **577**（ds:4 的该指标是本体绑定型，不过滤软删；ds:6 改为直接 SQL 后被软删重写）。
  属**口径差异**，不是数据或关联错误；同一题在 ds:4 通过。
- 其余此前暴露的问题已修：
  - 本体绑定指标停在 ds:4 实例数（化验 2527/批次 287）→ ds:6 改为直接 SQL；
  - 「备注不为空」偶发漏写 `<> ''` → ds:6 增加同义 few-shot，连测稳定 949。
