AIStation 对话嵌入 · 演示宿主页

模拟第三方站点：服务端换票 → 注入短期 token → iframe / Script SDK 两种嵌入形态。

⚠️ 生产环境必须在宿主服务端换票：本页为便于演示，把 appid/appkey 放在页面里模拟「宿主服务端」行为。真实接入时 appkey 只能保存在服务端，网页与嵌入代码中绝不能出现。

嵌入预览

iframe 直嵌模式：把 token 填入上方后也可直接在任意页面使用 <iframe src="{webBase}/#/embed?token=…">。
